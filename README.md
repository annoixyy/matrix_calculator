
# Matrix Calculator

Лабораторная работа №3 — «Полный цикл разработки калькулятора матриц на C++».

## Описание

Проект представляет собой библиотеку для работы с матрицами на C++17.

Реализованы основные операции:
- создание матрицы;
- освобождение памяти;
- сложение матриц;
- умножение матриц;
- вывод матрицы;
- создание матрицы из одномерного массива.

Индивидуальное задание, вариант 13: **выделение подматрицы**.

Функция `matrix_submatrix` получает исходную матрицу, начальную строку и столбец, а также размеры подматрицы.

## Структура проекта

- `include/matrix.h` — объявления функций и структуры Matrix;
- `src/matrix.cpp` — реализация функций;
- `src/main.cpp` — демонстрация работы программы;
- `tests/` — unit-тесты Google Test;
- `docs/` — документация Doxygen;
- `.github/workflows/ci.yml` — автоматическая сборка и проверка проекта;
- `Dockerfile` — сборка Docker-контейнера.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
./build/matrix_calculator
```

## Запуск тестов

```bash
ctest --test-dir build --verbose
```

## Проверка памяти

```bash
valgrind --leak-check=full --error-exitcode=1 ./build/tests/matrix_tests
```

## Документация

Сгенерировать документацию:

```bash
doxygen Doxyfile
```

HTML-документация находится в `docs/html/index.html`.

## Docker

Сборка образа:

```bash
docker build -t matrix-calculator .
```

Запуск контейнера:

```bash
docker run -it --rm matrix-calculator
```

## CI/CD

GitHub Actions автоматически выполняет настройку и сборку проекта, запускает тесты, проверяет память с помощью Valgrind и генерирует документацию.
